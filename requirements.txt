# Este script depende de pacotes do sistema e não deve ser instalado via pip.
# A biblioteca 'openrazer.client' é instalada através do gerenciador de pacotes da sua distribuição Linux.
#
# Para sistemas baseados em Debian/Ubuntu:
# sudo apt install python3-openrazer python3-evdev
#
# Para Arch Linux:
# sudo pacman -S python-openrazer python-evdev
#
# O acesso aos dispositivos de input (para detectar ociosidade via evdev) requer
# que seu usuário esteja no grupo 'input':
# sudo gpasswd -a $USER input
#
# Caso utilize um ambiente virtual (venv), crie-o permitindo acesso aos pacotes globais do sistema:
# python3 -m venv --system-site-packages venv
